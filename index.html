الإعدادات

المفتاح يُحفظ في متصفح هذا الجهاز فقط ولا يُرسل لأي جهة غير مزود الخدمة.

المستخدمون

هذه المنصة مغلقة: لا يستطيع أي زائر إنشاء حساب بنفسه. أضف حسابات من كان هنا فقط، وستعمل على هذا الجهاز.

كيف أحصل على مفتاح Gemini؟
  1. افتح صفحة مفاتيح Google AI Studio: aistudio.google.com/apikey
  2. سجّل الدخول بحساب جوجل عادي.
  3. اضغط Create API key وانسخ المفتاح.
  4. الصقه في الخانة أعلاه واضغط حفظ.
كيف أحصل على مفتاح OpenRouter؟ (احتياطي)
  1. افتح openrouter.ai وسجّل الدخول بحساب جوجل.
  2. افتح صفحة المفاتيح: openrouter.ai/settings/keys
  3. اضغط Create Key وانسخ المفتاح (يبدأ بـ sk-or-v1-).
  4. الصقه هنا واضغط حفظ.
